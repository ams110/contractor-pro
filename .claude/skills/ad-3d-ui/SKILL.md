# Ad 3D UI — بصريات ثلاثية الأبعاد فخمة لإعلانات Contractor Pro

سكيل **حِرفة إنتاج** (craft): يحوّل شاشات التطبيق لبصريات إعلانية 3D بمستوى وكالة —
موك-أب زجاجي طافي، ديوراما أيزومترية، طبقات UI منفصلة بالعمق، إضاءة سينمائية.
القرار الاستراتيجي (أي زاوية؟ أي جمهور؟ نصرف ولا لا؟) يبقى عند **`ad-strategist`** — هاد السكيل ينفّذ الإبداع.

## 🔴 القواعد الذهبية (قبل أي توليد)

1. **الشاشة الحقيقية أولاً**: أي موك-أب 3D يبدأ من سكرينشوت حقيقي للتطبيق (`npm run demo:shots` أو سكيل `promo-shots`). ممنوع تخلّي نموذج الصور «يخترع» واجهة التطبيق — بتطلع UI وهمية ما تشبه المنتج (وهاد غشّ إعلاني عملياً).
2. **النص العربي لا يُولَّد داخل الصورة**: نماذج الصور تكسّر الحروف العربية (تفكيك/عكس اتجاه). ولّد البصري **بلا أي نص**، وركّب العنوان/الـCTA بعدها كطبقة HTML في AdStudio (`/adstudio`) أو أي مركّب HTML→PNG. نفس القاعدة للعبري.
3. **الهوية**: خلفيات داكنة من عائلة `C.bg #07080F`، توهّج برتقالي `#F97316` → أحمر `#DC2626` (تدرّج `GRAD.brand`)، لمسات بنفسجي `#7C3AED` وسماوي `#06B6D4`. الإضاءة «الحارّة» هي بصمة البراند — لا أزرق بارد مهيمن.
4. **برومبتات التوليد بالإنجليزي** (النماذج تفهمه أدقّ) — حتى لو الإعلان النهائي عربي.
5. **مقاسات الإعلان**: 9:16 (1080×1920) لتيك توك/ستوري · 1:1 (1080×1080) و4:5 لفيد إنستغرام/فيسبوك. ولّد أكبر ثم قصّ (`reframe`/`outpaint_image` من Higgsfield).

## مسار A — توليد بالذكاء (Higgsfield) — الأسرع والأفخم

1. جهّز سكرينشوت الشاشة المطلوبة (هاتف، PNG حاد) عبر `promo-shots`/`demo-shots`.
2. ارفعه كمرجع (`media_upload` أو `media_import_url`).
3. اختر وصفة من **`reference/3d-recipes.md`** (10 وصفات جاهزة بنصّها الكامل) وولّد بـ`generate_image` (الافتراضي GPT Image 2؛ للالتزام الحرفي بالمرجع جرّب Nano Banana). مرّر السكرينشوت كصورة مرجعية واطلب صراحة: *"the phone screen must show exactly the provided UI screenshot, unaltered"*.
4. حسّن: `upscale_image` للدقة النهائية · `remove_background` إذا بدك العنصر مقصوصاً فوق خلفية AdStudio · `outpaint_image` لتوسيع الكادر لمقاس ثاني.
5. ركّب النص العربي/العبري + اللوغو + الـCTA في AdStudio أو صفحة HTML مؤقتة تصوّرها بـPlaywright.
6. (اختياري — إعلان فيديو): حرّك اللقطة النهائية بـ`generate_video` (image-to-video: دوران بطيء/parallax/توهّج نابض) — وكمّل بسكيل `ad-motion`.

## مسار B — CSS 3D حقيقي (AdStudio) — دقّة بكسل + UI حيّ

عندما بدك UI حقيقي 100% (أرقام، عربي RTL سليم، خطوط التطبيق نفسها):
- `perspective: 1200px` على الحاوية + `transform: rotateY(-18deg) rotateX(8deg) translateZ(0)` على موك-أب الهاتف.
- عمق بطبقات: بطاقات من الشاشة تطفو قدّام الهاتف بـ`translateZ(60–140px)` + ظل `0 40px 80px rgba(0,0,0,0.55)` + توهّج `0 0 120px rgba(249,115,22,0.25)`.
- انعكاس زجاجي: طبقة `linear-gradient(105deg, transparent 40%, rgba(255,255,255,0.08) 50%, transparent 60%)` فوق الشاشة.
- أرضية انعكاس: نسخة مقلوبة `scaleY(-1)` بـ`mask-image` متلاشي + `blur(6px)`.
- صوّر بـ`scripts/ad-shots.mjs` (DPR 2–4). التفاصيل والأكواد الجاهزة في `reference/3d-recipes.md` §CSS.

## متى أي مسار؟

| الحاجة | المسار |
|--------|--------|
| بوستر «واو» سينمائي، بيئة/إضاءة خيالية | A (توليد) |
| أرقام وواجهة لازم تكون حقيقية وحادّة | B (CSS 3D) |
| هجين (الأفخم): بيئة مولّدة + شاشة حقيقية مركّبة فوقها | A ثم تركيب الشاشة `remove_background`/طبقة HTML |

## سير العمل الكامل لإعلان

1. اسأل `ad-strategist` (أو المستخدم) عن الزاوية والجمهور — لا تولّد بصري بلا زاوية.
2. اختر وصفة + ولّد 2–3 تنويعات (لا تنويع واحد).
3. ركّب النص (هوك ≤ 7 كلمات، CTA واضح) — قوالب النص عند `ad-creative-lab`.
4. اعرض النتائج على المستخدم بـSendUserFile، ووثّق الإبداع المستعمل في `docs/ads/campaign-log.md` (ذاكرة ad-strategist).
