# Motion Cookbook — مرجع الموشن الإعلاني

## 1) جدول التوقيتات والإيزنغ

| الحركة | المدة | الإيزنغ |
|--------|------|---------|
| دخول نص (كلمة) | 300–420ms | `cubic-bezier(0.22,1,0.36,1)` (out-quint) |
| تتالي كلمات (stagger) | 80–120ms بين كلمة وكلمة | — |
| دخول بطاقة/عنصر UI | 450–600ms | spring 400/20 أو out-quint |
| انتقال مشهد (whip/zoom) | 250–400ms | `cubic-bezier(0.83,0,0.17,1)` (in-out-quint) |
| عدّاد رقم تصاعدي | 1200–1800ms | easeOutCubic (نفس `useCountUp` بالتطبيق) |
| نبض CTA | 900ms دورة | `ease-in-out` scale 1↔1.04 |
| خروج عنصر | 200–280ms (أسرع من الدخول دائماً) | in-quad |

**قواعد عامة**: الدخول أبطأ من الخروج · لا حركتين كبيرتين بنفس اللحظة (choreography: عنصر يقود والباقي يتبع بstagger) · حرّك `transform`/`opacity` فقط (لا width/top — أداء وتسجيل نظيف).

## 2) أنماط كينتك تايبوغرافي عربي (RTL)

- **Word pop**: كل كلمة تدخل `opacity 0→1` + `translateY(0.4em→0)` + `scale(0.9→1)`، stagger 100ms، من اليمين لليسار بترتيب القراءة.
- **الكلمة المفتاح**: آخر كلمة بالهوك تدخل أكبر (scale 1.3→1) بلون `#F97316` + وميض توهّج `text-shadow: 0 0 30px rgba(249,115,22,.6)` يخفت.
- **Line slam**: سطر كامل يهبط من فوق بسرعة مع اهتزاز خفيف (spring 500/14) — للأرقام الصادمة.
- **Strike-flip**: كلمة الألم («ورقة»؟ «دفتر»؟) يشطبها خط برتقالي يُرسم (scaleX 0→1 من اليمين) ثم تنقلب للبديل.
- **العداد**: أرقام `font-variant-numeric: tabular-nums` وزن 900، إشارة سالب `−` صريحة، ₪ أصغر من الرقم بـ40%.
- 🔴 لا تفكيك حروف عربية. التقطيع أصغر وحدة = **كلمة**.

## 3) مناطق الأمان تيك توك (1080×1920)

```
أعلى 220px    : يوزرنيم/متابعة — لا نص مهم
يمين 130px    : لايك/تعليق/مشاركة — لا CTA هون
أسفل 440px    : كابشن + شريط — لا نص مهم
الآمن         : x:[60,950] y:[240,1460] تقريباً
```
CTA النهائي: وسط الشاشة عمودياً (y≈900–1200) — مش تحت.

## 4) مسار 1 التفصيلي — HTML مُسجَّل بـPlaywright

1. أنشئ صفحة مشاهد مؤقتة (بالسكراتش باد أو `scripts/`): كل مشهد `<section>` ملء الشاشة 1080×1920، الأنيميشنات CSS keyframes/WAAPI تبدأ بحدث `start`، والمشاهد تتبدّل بجدول زمني JS (`setTimeout` تراكمي).
2. سجّل:
```js
const ctx = await browser.newContext({
  viewport: { width: 1080, height: 1920 },
  recordVideo: { dir: 'out/', size: { width: 1080, height: 1920 } },
});
const page = await ctx.newPage();
await page.goto('http://localhost:3000/ad-scene.html');
await page.evaluate(() => window.startTimeline());
await page.waitForTimeout(TOTAL_MS + 500);
await ctx.close(); // يفرغ الفيديو webm
```
3. معالجة ffmpeg:
```bash
# webm → mp4 تيك توك (H.264, 30fps)
ffmpeg -i in.webm -r 30 -c:v libx264 -pix_fmt yuv420p -crf 18 -movflags +faststart out.mp4
# قص أول ثواني التحميل
ffmpeg -ss 0.6 -i out.mp4 -c copy trimmed.mp4
# دمج مشاهد من مسارات مختلفة
printf "file 'hook.mp4'\nfile 'demo.mp4'\nfile 'cta.mp4'\n" > list.txt
ffmpeg -f concat -safe 0 -i list.txt -c:v libx264 -pix_fmt yuv420p final.mp4
# إضافة صوت
ffmpeg -i final.mp4 -i voice.mp3 -c:v copy -map 0:v -map 1:a -shortest final_audio.mp4
```
- عطّل مؤشر الماوس وscrollbars بالـCSS. استعمل خطوط التطبيق نفسها.
- للقطات «داخل التطبيق متحرّك»: افتح `/demoshot` الحقيقي وسجّل تفاعل مبرمج (تاب بين تبويبات، سكرول بطيء) — أصدق من أي محاكاة.

## 5) قوالب مشاهد جاهزة

- **Hook «الفوضى»**: 6–8 صور فواتير/دفاتر تتطاير للداخل بزوايا عشوائية (rotate ±12°) خلال 0.8s ثم تتجمّد، فوقها الكلمة تنفجر.
- **Flip «الحل»**: المشهد كله ينسحب بwhip-pan (translateX + blur 12px) → الهاتف يدخل بspring من تحت.
- **Demo بطاقة-رقم**: سكرينشوت يدخل، بطاقة منه تتكبّر للوسط (shared-element)، رقمها يعدّ، ✓ خضراء تنرسم.
- **Proof**: خلفية داكنة، رقم عملاق يعدّ + سطر صغير تحته («ساعة توفير باليوم»).
- **CTA**: لوغو الخوذة يهبط بspring، زر برتقالي `GRAD.brand` ينبض، سهم صغير يتحرّك.

## 6) تشيك-ليست قبل التسليم

- [ ] حركة قوية خلال أول 0.8s؟ أول فريم مش أسود/فاضي؟
- [ ] الرسالة مفهومة بلا صوت؟
- [ ] تغيير بصري كل ≤2.5s؟
- [ ] النص داخل المنطقة الآمنة؟ كل النصوص ≥48px (تُقرأ على موبايل)؟
- [ ] عربي RTL سليم (دخول من اليمين، لا حروف مقطّعة، لا خلط عربي/عبري بكلمة)؟
- [ ] إيزنغ غير خطّي بكل حركة؟ خروج أسرع من دخول؟
- [ ] CTA ثابت ≥2s بنبض؟
- [ ] 1080×1920، 30fps، H.264 yuv420p، ≤60s؟
- [ ] UI المعروض حقيقي (مش مولّد)؟
