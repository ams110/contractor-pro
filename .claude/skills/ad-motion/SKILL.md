# Ad Motion — موشن ديزاين إعلاني لـ Contractor Pro

سكيل **حِرفة إنتاج**: يحوّل الأفكار والبوسترات لفيديو إعلاني متحرّك بمستوى وكالة.
الاستراتيجية (الزاوية/الجمهور/الميزانية) عند **`ad-strategist`** — هون التنفيذ الحركي.
المرجع التفصيلي (توقيتات، إيزنغ، قوالب مشاهد، أوامر ffmpeg): **`reference/motion-cookbook.md`**.

## 🔴 قوانين الموشن الإعلاني (غير قابلة للتفاوض)

1. **الهوك خلال 0.8 ثانية**: أول فريم لازم فيه حركة قوية + عنصر فضولي. لا شعارات افتتاحية، لا fade-in بطيء من أسود. تيك توك يقرّر بالسكيب خلال ثانية.
2. **تغيير بصري كل 1.5–2.5 ثانية**: قطع مشهد، دخول نص، zoom — أي شي. الثبات = سكيب.
3. **مصمَّم للصامت**: 80%+ يشاهدون بلا صوت أول ثانيتين — النص المتحرّك يحمل الرسالة كاملة، والصوت إضافة.
4. **إيزنغ التطبيق نفسه** (اتساق براند): سبرينغ 340/30 للألواح، 400/20 للبطاقات، 400/17 للأزرار — أو `cubic-bezier(0.22, 1, 0.36, 1)` (easeOutQuint-ish) كبديل CSS. **ممنوع** `linear` أو `ease` الافتراضي لأي حركة ظاهرة.
5. **مناطق الأمان 9:16**: النص داخل الوسط — اترك ~220px فوق و~440px تحت (واجهة تيك توك تغطيهم) و~120px يمين (أزرار التفاعل). التفاصيل بالمرجع.
6. **عربي RTL**: النص يدخل من **اليمين** (اتجاه القراءة)، الكلمات تتراكم يمين→يسار. كلمة-كلمة (word-by-word reveal) أقوى من سطر كامل. لا تكسر كلمة عربية حرف-حرف أبداً (الحروف متصلة — التقطيع يكسر التشكيل البصري).
7. **CTA يثبت ≥ 2 ثانية** آخر الفيديو، بنبض خفيف (scale 1→1.04→1).

## هيكل الإعلان القياسي (15–30 ثانية)

| المشهد | المدة | المحتوى |
|--------|------|---------|
| Hook | 0–1.5s | حركة صادمة + سؤال/ألم («لسّا بتحسب رواتب العمّال عالورق؟») |
| Pain | 1.5–5s | تجسيد الفوضى (فواتير طايرة، دفتر، آلة حاسبة) |
| Flip | 5–7s | انتقال حاد (whip/zoom) → التطبيق يظهر |
| Demo | 7–18s | 2–3 لقطات UI حقيقية متحرّكة، رقم/نتيجة لكل لقطة |
| Proof | 18–24s | رقم كبير يعدّ تصاعدياً / شهادة |
| CTA | 24–30s | لوغو + زر + عرض («جرّب مجاناً») |

## مسارات الإنتاج الثلاثة

### مسار 1 — HTML/CSS/JS مُسجَّل (الأدقّ للـUI والعربي) ⭐ الافتراضي
مشاهد HTML بأنيميشن CSS/WAAPI/Framer-Motion → تسجيل فيديو بـPlaywright (`recordVideo` بمقاس 1080×1920) → قصّ ودمج بـffmpeg. UI حقيقي، عربي مثالي، تحكّم كامل بالفريمات. الوصفة الكاملة + قالب صفحة المشاهد في المرجع §4.

### مسار 2 — Higgsfield (سينمائي/خيالي)
- `generate_video` image-to-video: حرّك بوستر من `ad-3d-ui` (دوران بطيء، parallax، توهّج نابض) — لقطات Hook/Flip الفخمة.
- `generate_video` text-to-video (Seedance): لقطات حياتية (مقاول بالورشة).
- قصّ المقاسات بـ`reframe`، الصوت بـ`generate_audio`.
- **لا تولّد UI التطبيق بالذكاء** — اللقطات الواجهية دائماً من مسار 1 أو سكرينشوتات حقيقية.

### مسار 3 — Remotion (فيديو برمجي React كامل)
للإعلانات المركّبة (داتا حيّة، مئات الفريمات المضبوطة): ثبّت السكيل الرسمي `npx skills add remotion-dev/skills` ثم `npx create-video`. React components = فريمات، يدعم RTL بشكل ممتاز. استعمله لمّا مسار 1 يضيق (تزامن صوت دقيق، مشاهد داتا معقّدة).

> **الهجين الفائز عملياً**: Hook سينمائي من مسار 2 (2ث) + Demo من مسار 1 (10ث) + CTA من مسار 1 — دمج ffmpeg.

## سير العمل

1. خذ الزاوية من `ad-strategist` (اقرأ `docs/ads/campaign-log.md` — لا تكرّر إبداعاً مستهلكاً).
2. اكتب storyboard نصّي (جدول المشاهد أعلاه معبّأ) واعرضه سريعاً.
3. أنتج، ادمج، ثم افحص ضد **تشيك-ليست المرجع §6** (هوك؟ صامت؟ مناطق أمان؟ CTA؟).
4. ابعت الفيديو بـSendUserFile ووثّقه في `docs/ads/campaign-log.md`.
