## 🟠 ميزات مبنية جزئياً (نصف مؤتمت)

### 2. مكافأة الإحالة للمشترك Paddle النشط — يدوية حالياً
- **الحالة**: `grant_referral_reward` بتمنح شهر تلقائياً لغير المشترك (تمديد `trial_ends_at`)، لكن للمشترك النشط بتعلّم الصف `reward_pending` فقط — الشهر المجاني الحقيقي لسا يدوي.
- **المطلوب**: فرع في `paddle-webhook` يستدعي Paddle Discounts/Credits API خلف `PADDLE_API_KEY` لمنح خصم شهر فعلي، ثم تحديث الحالة لـ`rewarded`. (مصمَّم خامل-بأمان — بلا المفتاح يبقى يدوي.)
- **المصدر**: موجة الإحالة (PR #256). مرجع: `supabase/migrations/20260703020000_referrals.sql`، `supabase/functions/paddle-webhook/index.ts`.

### 3. واجهة الإحالات بلوحة الأدمن `/admin` — ناقصة
- **الحالة**: الـRPC `admin_list_referrals` + edge action `list-referrals` مبنيان وشغّالان، **بس ما في جدول بالواجهة** (`src/pages/AdminDashboard.jsx`) يعرض مين أحال مين وحالة كل إحالة والنص الحر (الإحالات الشفهية) — لازم لتنفيذ مكافآت `reward_pending` يدوياً.
- **المطلوب**: تبويب/جدول بسيط بلوحة `/admin` يستدعي `list-referrals` ويعرض النتائج.
- **المصدر**: موجة الإحالة (PR #256).
