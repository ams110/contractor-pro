# هوية كبلان الإعلانية — Brand DNA

> **المرجع البصري الرسمي لكل الإعلانات.** اللوحة الكاملة: `docs/brand/brand-board.png`
> (مولّدة بسكيل `brandkit` بتاريخ 08/07/2026 واعتمدها المالك كمنطلق).
> كل سكيلات الإعلانات (`ad-3d-ui` · `ad-motion` · `ad-creative-lab` · `ad-strategist`) تستمد منها.

## عناصر الهوية المقفولة

| العنصر | القيمة |
|--------|--------|
| **اللوغو** | خوذة `HardHat` بيضاء على بلاطة مدوّرة بتدرّج `linear-gradient(135deg, #F97316, #DC2626)` — **مصدره الحقيقي `public/icon-1024.png`** (مولّد بـ`generate_icon.py`، لا يُعاد رسمه يدوياً) |
| **الاسم** | كبلان · KABBLAN · Contractor Pro |
| **التاغلاين** | «Built to run the site.» — بالعربي: «مبني يدير الورشة.» / بالإعلان: «مصلحتك كلها. بجيبك.» |
| **الباليتة** | `#07080F` خلفية · `#12152A` بطاقة · `#F97316` برتقالي أساسي · `#DC2626` أحمر التدرّج · `#7C3AED` بنفسجي · `#06B6D4` سماوي (المصدر الموثوق: `src/constants/index.js`) |
| **الخط** | عربي ثقيل 800–900، حروف لاتينية Grotesque عريضة، `letter-spacing` ضيّق، أرقام `tabular-nums` |
| **الإضاءة** | مفتاح برتقالي دافئ من أعلى اليمين + rim أحمر + لمسة بنفسجية — **ممنوع أزرق بارد مهيمن** |

## لغة اللوحة (9 بانلات) → استعمالها الإعلاني

1. **بلاطة اللوغو** → افتتاحية/خاتمة كل فيديو (لوغو ستينغ `docs/brand/` أصل متحرّك مولّد منها).
2. **البناء الهندسي للخوذة** → خلفيات تقنية، لقطات «كيف انبنى».
3. **تطبيق الموبايل** → إطار موك-أب موحّد للإعلانات (شاشة حقيقية دائماً — قاعدة `ad-3d-ui` #1).
4. **التاغلاين الكبير** → قالب Headline Statement (قالب 1 بـ`ad-creative-lab`).
5. **أعمدة الألوان** → التزام صارم — أي إبداع خارج الباليتة يُرفض.
6. **تايبوغرافي KABBLAN** → لقطات كينتك (قواعد `ad-motion` §2).
7. **الخوذة الفعلية بالشعار** → بوستر «الخوذة البطل» (زاوية هوية: «إنت مقاول. مش محاسب.»).
8. **الورشة وقت الغروب** → درجة الألوان المرجعية لكل لقطات lifestyle.
9. **صف الأيقونات** → أيقونات Lucide بخط رفيع + chip برتقالي متوهّج واحد.

## قواعد الاستخدام

- الشاشات داخل أي موك-أب = سكرينشوت حقيقي (`promo-shots`) — لا UI مولّدة.
- النص العربي يُركّب HTML فوق البصريات المولّدة (النماذج تكسّر الحروف).
- مصطلحات عبرية بحروف عبرية نقية 100% — لا خلط بكلمة واحدة.
- التوليد المشتق: مرّر `brand-board.png` (أو job المرجعي) كصورة reference بكل استدعاء Higgsfield.
