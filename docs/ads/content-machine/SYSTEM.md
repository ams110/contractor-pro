## 1. المبادئ المثبتة (من بياناتنا الحقيقية — لا تُناقش، تُطبَّق)

1. **شاشة التطبيق تغلب كل شي** (32.1K مقابل 333 للشهادات) → كل أصل يحتوي شاشة حقيقية.
2. **القمع قبل التمويل**: الترافيك يودّي على مغناطيس (`/calculator`، `/demo`) — مش على حائط تسجيل.
3. **عضوي أولاً**، وعند التمويل: website visits فقط (CPM ₪1.95) — ممنوع أهداف مظهرية.
4. **تصدير نظيف** — بلا علامة مائية (قتلت الوصول العضوي سابقاً).
5. **زوايا محروقة ممنوعة**: شهادة الحاج العامة · مقارنة المحاسب المباشرة كإعلان منفرد · بوسترات ثابتة كإعلان.
6. عبري نقي 100% (فحص regex `[֐-׿]` vs `[؀-ۿ]`) + أسماء عبرية بالواجهة العبرية (`buildDemo(lang)`).
7. 9:16 · 1080×1920 · هوك <3ث · كابشن محروق · مناطق آمنة (أسفل 320px، يمين 120px).

## 3. أوامر الإنتاج

```bash
npm run dev                                      # سيرفر :3000 (شرط لكل الرندر)
IDEAS=0,3,4 node scripts/reel-shots.mjs          # ريلات عربي (عمود A/C)
LANG=he IDEAS=9,10 node scripts/reel-shots.mjs   # ريلات عبري (عمود B) — بعد إضافة الأفكار لـ IDEAS_HE
npm run ads:shots                                # بوسترات ستوري (عمود C)
```
- عمود D/E: توليد المشهد الواقعي عبر Higgsfield MCP (`generate_image`/`generate_video` 9:16) ثم دمج مع لقطات `demoshot` بـ ffmpeg (نفس سلسلة `reel-shots`).
- عمود F: قصّ/تركيب من مخرجات A–E الفائزة + CTA يوتيوب («الرابط بالوصف»).

## 4. الروابط والقياس (UTM إلزامي)

| وجهة | متى | نمط |
|------|-----|-----|
| `/calculator` | عمود C (والبايو وقت دفعة C) | `?utm_source=tiktok&utm_medium=organic&utm_campaign=cm-calc-{ar\|he}` |
| `/?lang=he` أو `/` | أعمدة A/B/D/E (بايو) | `utm_campaign=cm-{pillar}-{id}` |

**مقياس النجاح الحقيقي**: تسجيلات فعلية (`auth.users` / لوحة `/admin`) — مش مشاهدات. الأهداف: Hook rate >30% · تسجيل واحد على الأقل لكل دفعة منشورة · CPL <330₪ عند التمويل.

## 5. إيقاع النشر (من ترندات 2026: 3–5 منشورات/أسبوع لكل صفحة)

- **تيك توك عربي**: 4/أسبوع (أحد–خميس، 7–10م) — تناوب A → C → D → E.
- **تيك توك عبري**: 4/أسبوع — تناوب B → C(he) → D(he) → E(he).
- **YouTube Shorts**: 2/أسبوع من عمود F (يبدأ بعد أسبوعين — نرفع الفائزين فقط).
- ~8 أسابيع لتصريف الـ100 أصل. **ممنوع نشر دفعة واحدة** — الخوارزمية تكافئ الانتظام.
